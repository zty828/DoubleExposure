## 3. Demo 范围（锁定，防 scope creep）
- 一个站舱模块，**3 房间**（关卡 A / B / C）。
- 记录时长 **60–90 秒**，2–3 个记录幽灵角色。
- **3 个可提取物体**（栏杆、钥匙卡、证据物）+ 若干可回溯物体（无人机电芯、哨兵装甲、桥 / 门）。
- **1 种敌人**（装甲哨兵）+ **1 把枪**。
- **20 分钟**线性体验，三动词各教一次，关卡 C 高潮。
- 不做：开放世界 / 多敌人种类 / 复杂枪械 / 长播片 / 因果连锁。

## 5. 技术方向与约束（只给方向，具体待实机验证）

### 5.1 硬约束（已查证）
- **写实可行但必须移动配方**：烘焙光照 + 4x MSAA（PICO 4 可 2x）+ FFR + 合并压 draw call + 极少动态光 + cubemap 反射。移动着色路径当前基线 = **Deferred + MSAA**（Host59 验证组合）；若真机 MSAA 不生效或性能不达标回退 **Forward + MSAA**。**禁** Lumen / Nanite / 硬件光追 / 平面反射 / 重后处理。
- **目标帧率**：稳定 ≥ 72fps（官方商店审核底线）；Ultra 原生 90Hz → 90 为目标、72 为底线。
- **PICO 4 Ultra**：XR2 Gen2 / 12GB / 90Hz / **无眼动无面部追踪** → 视线类用头朝向。
- **引擎版本**：官方 PICO Unreal OpenXR 插件支持 UE 5.2–5.8；UE 5.9 不在官方列表。**已决策（2026-11-17）：采用 UE 5.9 预览版 + 自适配 PICOOpenXR 6.1.4**（团队已交付适配，见 repo/PICOOpenXR-UE5.9）；起始工程 DoubleExposure/ 已建并完成配置真值复验（见 README.md）。

### 5.2 设计级技术方向（不预设实现）
- 记录 = **固定 kinematic 回放**（authored 动画，非物理模拟）；幽灵 = 半透明 actor 叠加现在态，**非第二套完整世界渲染**。
- 提取 = 复制物体快照为锚定物（离散状态，非实时模拟）。
- 切换 = 两套 authored 状态 toggle（共享几何 + 材质 / 光照 / actor 可见性），烘焙双 lightmap 或 sublevel。
- 回溯 = authored 状态机插值（有限档位）。
- **全程无自由物理回放。**
