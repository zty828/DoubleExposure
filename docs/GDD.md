# 双重曝光 / DOUBLE EXPOSURE — 游戏设计文档 (GDD)

版本 v0.1 · 2026-11-17 · 状态：设计定稿，待原型验证
配套文档：PRODUCTION.md（比赛事实 / 排期 / 范围 / 风险 / 提交清单）

> 本文档以**设计**为准。技术实现只给方向与约束，不预设具体方案——具体实现待实机验证后补充（见 PRODUCTION.md「待实机验证清单」）。

## 1. 一句话与定位

> **时间是可编辑的，编辑有三个粒度：整段世界（切换）、单个物体（回溯）、跨时刻搬运（提取）。一只手腕装置，三个动词，一个主题。**

- 类型：线性叙事解谜 + 轻战斗，第一人称 VR。
- 风格：写实科幻，微风格化（仅全息记录层）。气质对标《红色物质 Red Matter》：孤立、冷峻、工业、叙事悬疑。
- 平台：PICO 一体机（4 / 4 Ultra），Unreal Engine + OpenXR。
- 赛事：PICO 2026 开发者大赛 ·「最佳沉浸内容创作」赛道（Unity / Unreal OpenXR SDK 全沉浸式体验）。
- 商业愿景：demo 验证后扩充为 4–6h 完整商业作，定位「时间侦探」子类型。

## 2. 设计支柱

1. **一套语法，三个粒度**：所有玩法都是「编辑时间」，不堆砌独立 gimmick。
2. **机制即叙事**：scrub 记录找可提取物的过程，本身就在揭示灾变真相。
3. **多解优先**：每个核心谜题至少两条动词路径。
4. **确定性高于模拟**：回放 / 回溯走 authored 状态，不做自由物理回放。
5. **舒适与清晰**：瞬切无相机运动；每个可编辑物体有明确视觉 tell。

## 3. 非目标（demo 不做）

- 开放世界 / 生存撤离 / 建造 / 多人。
- 自由物理回放、实时因果连锁、Lumen / Nanite / 平面反射。
- 恐怖调性（科幻悬疑，非 jump scare）。
- 复杂枪械库 / 大量敌人种类（demo 仅 1 种敌人 + 1 把枪）。
- 眼动交互（PICO 4 Ultra 无眼动 / 面部追踪）。

## 4. 核心机制：三动词时间语法

### 4.1 世界观基础
- **子午线研究站（Meridian Station）** 进行「时相实验」，灾变后站体分裂为两套时间状态：
  - **【过去态】** 灾变前：站体完好、系统运转、有维护机器人。
  - **【现在态】** 灾变后：站体废墟、坍塌、锈蚀、被腐蚀的安保单位敌对。
- 玩家腕上的「时相装置」是实验原型机，能编辑时间。玩家是跨时间线的常量。

### 4.2 动词一 · 切换（世界粒度）
- **输入意图**：手腕 flick / 专用键，整个空间在【过去态】↔【现在态】间瞬切。
- **表现**：瞬切 + 短暂 blink/vignette（约 0.15s），**无相机运动**；色调 / 音景整体切换（过去 = 运转嗡鸣 + 冷白；现在 = 风噪 + 吱嘎 + 暗琥珀）。
- **规则**：切换只改「世界参照系」，不改玩家位置 / 朝向。
- **用途**：找路（过去有桥现在断）、取物（现在锁死过去开着）、躲 hazard、flank 敌人。

### 4.3 动词二 · 回溯 / 老化（物体粒度）
- **输入意图**：指向单个物体 + 扣扳机保持，沿该物体**自己的**时间线倒带（复原）或快进（锈蚀 / 老化）；方向由摇杆 / 手势决定。
- **表现**：物体表面扫过一道时间波纹，mesh / 材质在 authored 状态间插值（完好 ↔ 锈蚀 ↔ 断裂 ↔ 成灰）。
- **规则**：
  - 只作用于「可编辑物体」（有明确高亮 tell），世界其余不动。
  - 每个物体有**有限 authored 状态**（如 3–5 档），非任意物理。
  - 被编辑过的物体成为【锚定物】（见 4.5）。
- **用途**：修桥 / 修门、老化障碍成灰、锈化敌人装甲、倒带 thrown grenade。

### 4.4 动词三 · 提取（跨时刻粒度）— 新鲜度核心
- **输入意图**：进入「记录模式」，腕装置投影出本空间**灾变前最后 N 分钟的固定记录**；拨盘 scrub 倒带 / 快进；在某一帧伸手抓住高亮物体 → 提取到现在。
- **表现**：
  - 记录以**全息幽灵叠加在【现在态】世界上**（现在几何不变，过去的人 / 物以扫描线 / 点云微风格化幽灵呈现）。
  - 可提取物体在记录里高亮描边；抓取瞬间幽灵「凝聚」成实体落在玩家手中 / 面前。
- **规则（防悖论，关键）**：
  - 记录是**只读固定回放**，不可被玩家改变 → 无因果循环。
  - 提取 = **复制该帧物体快照**到现在；记录里的幽灵继续存在、记录继续播放（你拿的是快照，不是「偷走导致过去缺失」）。
  - 提取物成为【锚定物】。
  - 每个可提取物体每局只能提取一次（demo 限制，防滥用）。
- **用途**：拿现在已毁 / 已失的钥匙卡、保险丝、工具、证据；提取过去存在现在已毁的掩体 / 栏杆。
- **叙事耦合**：scrub 记录 = 看灾变前最后一刻的人做了什么 → 机制即叙事。

### 4.5 锚定规则（统一三动词的关键）
> **你动过的东西，就归你了，不再跟着世界变。**

- 被提取或被回溯 / 老化编辑过的物体 = **锚定物**。
- 锚定物是**唯一允许跨时间线存在的例外**：切换世界时它保持你编辑后的状态，不随世界态变化。
- 未编辑物体严格跟随当前世界态。
- **视觉 tell**：锚定物带持续微弱时间波纹 / 描边，区别于世界物体。
- **设计意义**：锚定物是玩家在两套世界间「搭桥」的工具，也是把复杂度关进笼子的规则（只有锚定物跨态，其余确定）。

### 4.6 三动词如何共享一套系统
- 每个可编辑物体只有**一条规范时间线**（authored 状态序列）。
- 切换 = 换世界参照系（看哪套全局态）。
- 回溯 = 在参照系内移动某物体的状态指针。
- 提取 = 把记录某帧的物体快照复制为锚定物。
- **三者共用同一物体状态机，不是三套独立系统。**

## 5. 关卡设计（demo 三关）

### 5.1 关卡 A · 坍塌的桥（教学三动词，多解）
- **空间**：站舱入口段，一道断桥挡住去路；过去态桥完好但有巡逻无人机。
- **教学顺序**：先切换（看到两套世界）→ 再回溯（无人机电芯倒到没电）→ 再提取（记录里桥完好那帧提取栏杆）。
- **解法 1（切换 + 回溯）**：切过去 → 回溯无人机电芯到没电 → 过去态安全过桥。
- **解法 2（提取）**：scrub 记录到桥坍塌前 → 提取一段完好栏杆锚定到现在 → 现在态通行。
- **验收**：玩家能独立发现至少一条路径；两条路径都被 playtest 验证可解。

### 5.2 关卡 B · 装甲哨兵（战斗 = 时间编辑）
- **空间**：中段舱室，一台被腐蚀的装甲哨兵堵门，正面打不动。
- **过去态**：哨兵还是无害维护机器人（未敌对，不能打）。
- **解法 1（回溯 + 锚定）**：切过去 → 回溯它的装甲板到锈蚀态（成为锚定物）→ 切回现在 → 装甲已锈 → 射击弱点。
- **解法 2（提取）**：scrub 记录到它「未装弹时刻」→ 提取空弹匣到现在替换 → 现在它卡壳 → 通过 / 击杀。
- **战斗爽点**：在时间维度上拆解敌人，不是枪法。
- **验收**：两种解法可解；战斗节奏不拖（哨兵 1 台，枪 1 把）。

### 5.3 关卡 C · 提取 Showcase + 叙事 payoff
- **空间**：实验室前厅 + 实验室。
- **记录显示**：灾变前一刻，研究员林某持卡走向实验室，画面被事故打断。
- **玩法**：scrub 到她持卡那帧 → 提取钥匙卡 → 开实验室门。
- **叙事钩子**：scrub 过程看到她持卡前是**从另一人手里夺的卡** → 提取证据物 + 观察记录 → 揭开「事故不是意外」。
- **高潮**：机制高潮（提取）与叙事高潮（真相）重合 → 路演演示这一段。
- **验收**：玩家提取钥匙卡开门；至少注意到一条叙事异常（夺卡）。

## 6. 叙事
- **背景**：子午线研究站时相实验灾变，站体时间态分裂。玩家是事后派入的回收 / 调查员，腕戴实验原型时相装置。
- **主线（demo 只露一角）**：事故不是意外，是人为（夺卡 / 破坏）。完整真相留给商业版。
- **叙事载体**：环境叙事（两套世界态对比）+ 记录幽灵（灾变前最后一刻）+ 少量音频日志 + 提取物证。
- **不做**：长播片、大量对白、复杂分支（demo 线性）。
- **角色（记录幽灵，demo 2–3 人）**：研究员林某（持卡 / 夺卡）、另一研究员（被夺卡）、维护机器人（哨兵前身）。

## 7. 美术方向
- **主体**：写实工业科幻，冷峻金属 / 混凝土 / 管线；冷白（过去）vs 暗琥珀锈蚀（现在）。
- **微风格化仅限记录层**：全息幽灵用扫描线 / 点云 / 半透明青蓝，与写实主体形成「记录 vs 现实」的视觉区分。
- **两套世界态共享几何**：同一套 mesh，换材质 / 光照 / 损伤 decal / actor 可见性 → 压美术成本。
- **锚定物 / 可编辑物体**：持续微弱时间波纹描边（清晰 tell）。
- **参考气质**：Red Matter 1/2 的孤立工业悬疑；不做卡通 / 低多边形。

## 8. VR 交互与舒适
- **移动**：传送（默认）+ 平滑移动（可选），支持坐姿 / 站姿。
- **三动词输入意图**（具体按键映射待实机验证，避免手势冲突）：
  - 切换：非惯用手腕 flick 或专用键（不与抓取冲突）。
  - 回溯：惯用手指指向 + 扳机保持 + 摇杆前后决定倒带 / 快进。
  - 提取：进入记录模式（专用键）→ 摇杆 scrub → 伸手抓取高亮物。
- **舒适**：瞬切无相机运动 + 短 blink；记录模式 stationary；无强制头部运动；视线类不依赖眼动。
- **清晰**：每个可编辑 / 可提取物体有明确高亮；锚定物有持续 tell；记录 scrub 有时间刻度 UI（腕上 holographic dial）。
- **待验证**：三动词手势是否冲突、记录模式抓取是否自然、瞬切是否晕动（见 PRODUCTION 验证清单）。

## 9. 音频
- 空间音频；两套世界态音景对比（过去运转嗡鸣 / 现在风噪吱嘎）。
- 记录幽灵带「时代感」闷音 / 滤波，scrub 时音调随速度变化。
- 切换 whoosh + 音调 shift；回溯时间波纹声；提取凝聚声。
- 少量音频日志推进叙事。

## 10. 商业扩充路径（demo 之后）
- 更多章节 / 站点（每站一套两态 + 一段记录）。
- 更长记录、多敌人时间编辑、提取物组合谜题。
- 叙事主线展开（事故真相、夺卡背后、时相实验伦理）。
- 锚定物守恒 / 因果连锁作为后期高级机制（demo 不做，见 §12 备选）。
- 目标 4–6h 完整商业作。

## 11. 新鲜度与先例（诚实定位）
- **组件 proven**：切换 = Titanfall 2「Effect and Cause」/ Dishonored 2「A Crack in the Slab」；回溯 = Singularity TMD / The Entropy Centre（无 VR 版）；记录观察 = The Invisible Hours（纯旁观，不能提取）。
- **新鲜的是组合**：「三粒度统一语法 + 从固定记录提取物体」，VR 无高品质先例。
- **最接近**：学生原型 Paradox Rift（过去 → 现在位移）、itch 微型分身 / 过去自我实验（Playback / Zeit Geist）→ 原型多但没人做精。
- **措辞纪律**：说「VR 首个高品质三粒度时间编辑 + 记录提取」，**不说「VR 首创时间机制」**。

## 12. 备选第三元素（若提取原型失败）
- **备选 X · 锚定物守恒**：被编辑物体成锚，切换时不变；纯逻辑解谜，工程最省（无记录回放系统），叙事弱。
- **备选 Y · 因果连锁**：过去态改物体 → 现在态实时联动；蝴蝶效应解谜，但双态一致性 authoring 风险高，5 周不推荐。
- **决策点**：W1 原型验证提取可行性；若记录回放 / 抓取成本超预期，退备选 X。
